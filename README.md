# 傲天课表

个人课表网页：按周次滚动查看上课安排，日期自动联动，支持编辑、导入、配色与分享。

## 功能

- **周次查看**：◀ ▶ 切换周次，显示具体日期（9月7日 = 第1周周一）
- **编辑课表**：点「编辑课表」自己添加/修改/删除课程
- **导入 Excel / CSV**：按模板填写后一键导入，自动排版课表
- **配色**：统一或随机配色，无课颜色为保留色
- **节次设置**：自定义每节课的时间（适应不同学校）
- **下载分享**：修改的数据保存在本浏览器；点「下载课表」生成含最新课表的 HTML 文件，转发即可分享

## 使用方法

直接打开本仓库的 Pages 网址，或下载 `index.html` 用浏览器打开即可，无需安装。

## 导入模板

按「课表导入模板」填写：表头行必须保留，课程从第 5 行开始填；
周次支持连续（`1-18`，英文短横线）和间隔（`3,5,7`，英文逗号），可混用。

## 部署

本页面为单文件 HTML，可部署到任意静态托管平台（GitHub Pages / Netlify 等），
也可添加到手机主屏幕作为 App 使用。
